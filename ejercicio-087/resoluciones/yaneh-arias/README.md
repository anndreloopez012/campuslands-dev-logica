# Ejercicio 087: Secuencias Numéricas en Lista de Reproducción Musical

## ¿Cómo pensé el problema?
1. Analicé las entradas: un arreglo con las duraciones en segundos de las canciones que componen la lista de reproducción.
2. Recorrí la secuencia comparando cada elemento con su sucesor inmediato mediante un ciclo condicional.
3. Determiné si la lista cumple con el patrón de una secuencia numérica creciente o si presenta alteraciones en el orden.

## Reglas Aplicadas
* Validación de arreglos cortos o vacíos.
* Verificación secuencial iterativa para detección de patrones.

## ¿Cómo ejecutar la solución?
1. Abre tu terminal en: \ejercicio-087/resoluciones/yaneh-arias/\
2. Ejecuta: \
ode yaneh-arias.js\

## Casos Probados
* **Caso Normal:** Secuencia de duraciones en orden ascendente ([120, 150, 180, 210]).
* **Caso Borde:** Secuencia desordenada para comprobar la detección correcta de ruptura en la regla.
