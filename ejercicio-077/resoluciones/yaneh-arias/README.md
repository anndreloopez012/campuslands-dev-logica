# Ejercicio 077: Estadísticas de Ranking en Arquitectura 3D

## ¿Cómo pensé el problema?
1. Analicé las entradas: un conjunto de puntuaciones obtenidas por los proyectos de arquitectura 3D en el ranking.
2. Recorrí los datos acumulando la suma para calcular el puntaje promedio, y comparé cada valor para identificar el puntaje máximo y mínimo.
3. Estructuré los resultados en un objeto de salida claro con su respectiva validación de datos vacíos.

## Reglas Aplicadas
* Validación estricta de listas vacías para prevenir divisiones por cero.
* Uso de ciclos y condicionales para hallar extremos numéricos.

## ¿Cómo ejecutar la solución?
1. Abre tu terminal en: \ejercicio-077/resoluciones/yaneh-arias/\
2. Ejecuta: \
ode yaneh-arias.js\

## Casos Probados
* **Caso Normal:** Lista con cinco calificaciones de proyectos de arquitectura 3D.
* **Caso Borde:** Lista vacía para verificar la respuesta segura del sistema.
