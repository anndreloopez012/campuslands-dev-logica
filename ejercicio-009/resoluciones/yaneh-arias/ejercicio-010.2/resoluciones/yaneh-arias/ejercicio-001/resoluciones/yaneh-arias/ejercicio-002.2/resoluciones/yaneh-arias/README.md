
# Explicación del Problema 002.2

- **Análisis:** He diseñado un algoritmo que clasifica los puntajes mediante una estructura condicional.
- **Lógica:** Se aplicó una regla de negocio donde el bono se ajusta según el rendimiento (umbral de 50 puntos).
- **Cómo probarlo:**
    1. Usar una lista: [40, 60] y bono 10.
    2. 40 <= 50: 40 + 10 = 50.
    3. 60 > 50: 60 + 20 = 80.
    4. Resultado final = 130.
