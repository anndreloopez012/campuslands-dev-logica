
# Ejercicio 036: Presupuestos y Descuentos (Animación 3D)

## 🚀 Descripción del Problema
Este reto consiste en procesar datos numéricos bajo la temática de animación 3D, aplicando un ciclo acumulador para sumar costos de producción, aplicando reglas condicionales de descuentos porcentuales, y ajustando el resultado final con bonos y penalizaciones.

## 🛠️ Reglas Aplicadas
1. **Validación:** Se verifica que la lista de participantes o costos contenga elementos.
2. **Ciclo y Acumulador:** Se recorre el arreglo acumulando el presupuesto total base.
3. **Descuento y Cálculo Numérico:** Se evalúa si aplica un descuento porcentual según el monto acumulado, integrando posteriormente el bono y la penalización.
4. **Condicionales:** Se clasifica el proyecto de animación según el puntaje final obtenido ("estudio 3D avanzado", "render en proceso", "proyecto low-poly").
