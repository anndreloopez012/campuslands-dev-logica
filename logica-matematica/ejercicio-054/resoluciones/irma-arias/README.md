
# Ejercicio 054: Áreas y Perímetros (Tatuajes)

## 🚀 Descripción del Problema
Este reto consiste en procesar arreglos numéricos bajo la temática de tatuajes, aplicando lógica geométrica para simular el cálculo de áreas y perímetros de diseños de piezas corporales, ponderando el resultado con bonos y penalizaciones.

## 🛠️ Reglas Aplicadas
1. **Validación:** Se comprueba que el arreglo de datos contenga elementos.
2. **Cálculo Geométrico:** Se recorre la lista simulando dimensiones (ancho y alto) a partir de los valores para obtener las métricas promedio de área y perímetro.
3. **Puntaje Numérico:** Se computa una relación proporcional entre el área y el perímetro, sumando el bono y restando la penalización.
4. **Condicionales:** Se clasifica el tipo de trabajo artístico según su escala ("tatuaje de manga completa", "tatuaje mediano", "tatuaje minimalista").
