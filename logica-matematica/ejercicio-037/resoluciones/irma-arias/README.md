
# Ejercicio 037: Estadísticas de Ranking (Arquitectura 3D)

## 🚀 Descripción del Problema
Este reto consiste en procesar arreglos numéricos bajo la temática de arquitectura 3D, aplicando un ciclo acumulador, evaluación de estadísticas de ranking (identificación de valores máximos y promedios), y ajustando el puntaje final con bonos y penalizaciones.

## 🛠️ Reglas Aplicadas
1. **Validación:** Se verifica que la lista de participantes contenga elementos.
2. **Ciclo y Ranking:** Se recorre el arreglo calculando la suma total y detectando el puntaje más alto (máximo del ranking).
3. **Cálculo Numérico:** Se integra el promedio de los puntajes con el líder del ranking, sumando el bono y restando la penalización.
4. **Condicionales:** Se clasifica el nivel del profesional según el puntaje final obtenido ("arquitecto senior BIM", "modelador 3D estructurado", "diseñador novato").
