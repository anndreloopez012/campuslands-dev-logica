
# Ejercicio 049: Módulos y Divisibilidad (Películas de Miedo)

## 🚀 Descripción del Problema
Este reto consiste en procesar arreglos numéricos bajo la temática de películas de miedo, aplicando ciclos acumuladores, evaluación de operadores módulo para comprobar divisibilidad y ajustando el puntaje final con bonos y penalizaciones.

## 🛠️ Reglas Aplicadas
1. **Validación:** Se verifica que la lista de datos de entrada contenga elementos.
2. **Ciclo y Divisibilidad:** Se recorre el arreglo calculando el promedio total y contando cuántos números son divisibles exactamente entre 3 mediante el operador módulo (`%`).
3. **Cálculo Numérico:** Se computa el resultado combinando el promedio, bonificación por elementos divisibles, bono general y penalización.
4. **Condicionales:** Se clasifica el nivel del resultado según las categorías temáticas ("nivel terror psicologico", "suspenso moderado", "susto leve").
