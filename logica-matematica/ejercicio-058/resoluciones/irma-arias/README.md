

# Ejercicio 058: Normalización de Puntajes (Soldadura)

## 🚀 Descripción del Problema
Este reto consiste en procesar arreglos numéricos bajo la temática de soldadura, aplicando fórmulas de normalización estadística (escalado de datos entre mínimos y máximos), ponderando el resultado final con bonificaciones y penalizaciones.

## 🛠️ Reglas Aplicadas
1. **Validación:** Se comprueba que el arreglo de datos contenga elementos.
2. **Normalización:** Se identifican los valores extremos del conjunto para escalar cada puntaje de forma relativa y obtener un promedio normalizado.
3. **Puntaje Numérico:** Se integra el promedio escalado, sumando el bono y restando la penalización.
4. **Condicionales:** Se clasifica la calidad del trabajo de soldadura ("soldadura estructural certificada", "cordon de soldadura estandar", "revision de soldadura requerida").
