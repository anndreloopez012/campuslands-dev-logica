
# Ejercicio 030: Redondeo y Precisión (Viajes y Turismo)

## 🚀 Descripción del Problema
Este reto consiste en procesar datos numéricos con decimales bajo la temática de viajes y turismo, aplicando un ciclo acumulador, operaciones aritméticas con bonos y penalizaciones, y utilizando funciones nativas de redondeo (`Math.round` y `.toFixed`) para garantizar precisión en el resultado final.

## 🛠️ Reglas Aplicadas
1. **Validación:** Se verifica que la lista de participantes contenga elementos.
2. **Ciclo y Acumulador:** Se recorre el arreglo sumando los valores decimales de forma precisa.
3. **Redondeo Numérico:** Se aplica un redondeo al cálculo consolidado para obtener un puntaje final exacto.
4. **Condicionales:** Se clasifica al grupo según el puntaje obtenido ("viajero elite", "turista frecuente", "explorador novato").
