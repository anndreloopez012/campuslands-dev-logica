
# Ejercicio 059: Validaciones Numéricas (Fórmulas Químicas)

## 🚀 Descripción del Problema
Este reto consiste en procesar arreglos numéricos bajo la temática de fórmulas químicas, aplicando controles estrictos de validación numérica (filtrado de tipos de datos, validación de rangos lógicos y manejo de valores negativos o fuera de norma), ponderando el resultado con bonos y penalizaciones.

## 🛠️ Reglas Aplicadas
1. **Validación Estricta:** Se comprueba que el arreglo contenga datos y se filtran elementos no numéricos o negativos (simulando rangos de validez estequiométrica).
2. **Cálculo Numérico:** Se calcula el promedio a partir de los datos debidamente validados.
3. **Puntaje y Ajuste:** Se computa el resultado sumando el bono y restando la penalización.
4. **Condicionales:** Se clasifica el estado del compuesto químico ("formula molecular estable", "compuesto en balance", "reaccion inestable").
