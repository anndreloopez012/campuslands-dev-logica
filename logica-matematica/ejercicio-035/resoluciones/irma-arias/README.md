
# Ejercicio 035: Velocidad, Tiempo y Distancia (Dibujo Digital)

## 🚀 Descripción del Problema
Este reto consiste en procesar datos numéricos bajo la temática de dibujo digital, aplicando un ciclo acumulador, cálculo de proporciones de velocidad y distancia por cada elemento, y sumando bonos y penalizaciones para obtener una puntuación y clasificación final.

## 🛠️ Reglas Aplicadas
1. **Validación:** Se verifica que la lista de participantes contenga elementos.
2. **Ciclo y Física del Trazo:** Se recorre el arreglo acumulando los valores base y calculando la velocidad promedio a partir de los datos.
3. **Cálculo Numérico:** Se integra el factor de velocidad calculado al puntaje total junto con el bono y la penalización.
4. **Condicionales:** Se clasifica al artista o trazo según el puntaje obtenido ("ilustrador experto", "diseñador fluido", "trazo lento").
