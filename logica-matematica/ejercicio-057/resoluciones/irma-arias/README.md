
# Ejercicio 057: Estadísticas de Ranking (Arquitectura 3D)

## 🚀 Descripción del Problema
Este reto consiste en procesar arreglos numéricos bajo la temática de arquitectura 3D, aplicando lógica de análisis estadístico de ranking (ordenamiento de datos, identificación de valores máximos, mínimos y promedios), ponderando el resultado con bonos y penalizaciones.

## 🛠️ Reglas Aplicadas
1. **Validación:** Se comprueba que el arreglo de datos contenga elementos.
2. **Análisis Estadístico:** Se ordena el arreglo para extraer el puntaje máximo del ranking y calcular el promedio general de los proyectos.
3. **Puntaje Numérico:** Se computa una media ponderada entre el promedio y el mejor ranking, sumando el bono y restando la penalización.
4. **Condicionales:** Se clasifica el nivel del proyecto de arquitectura 3D ("render fotorrealista master", "modelado arquitectonico avanzado", "boceto estructural 3D").
