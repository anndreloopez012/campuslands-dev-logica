
# Ejercicio 047: Secuencias Numéricas (Lista de Reproducción Musical)

## 🚀 Descripción del Problema
Este reto consiste en procesar arreglos numéricos bajo la temática de lista de reproducción musical, aplicando ciclos acumuladores, evaluación de secuencias o progresiones entre elementos sucesivos y ajustando el puntaje final con bonos y penalizaciones.

## 🛠️ Reglas Aplicadas
1. **Validación:** Se verifica que la lista de datos de entrada contenga elementos.
2. **Ciclo y Secuencia:** Se recorre el arreglo para calcular la suma total y evaluar la progresión o diferencias numéricas entre pistas consecutivas.
3. **Cálculo Numérico:** Se computa el resultado combinando el promedio, la variación de la secuencia, el bono y la penalización.
4. **Condicionales:** Se clasifica el tipo de lista según su comportamiento ("playlist dinamica", "ritmo constante", "secuencia basica").
