
# Ejercicio 043: Promedios y Medianas (Torneo de Esports)

## 🚀 Descripción del Problema
Este reto consiste en procesar arreglos numéricos bajo la temática de torneos de deportes electrónicos, aplicando ciclos acumuladores, cálculo de promedios estadísticos y determinación de la mediana mediante ordenamiento, ajustando el resultado final con bonos y penalizaciones.

## 🛠️ Reglas Aplicadas
1. **Validación:** Se verifica que la lista de participantes contenga elementos.
2. **Ciclo y Acumulador:** Se obtiene la suma total para calcular la media aritmética (promedio).
3. **Cálculo de Mediana:** Se ordenan los datos de forma ascendente para aislar o promediar el valor central (mediana).
4. **Condicionales y Operación:** Se calcula el puntaje final combinando la mediana, un porcentaje del promedio, el bono y la penalización, clasificando al equipo ("equipo profesional tier 1", "competitivo", "fase clasificatoria").
