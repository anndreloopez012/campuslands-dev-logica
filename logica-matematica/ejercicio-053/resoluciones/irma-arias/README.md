
# Ejercicio 053: Coordenadas y Distancia (Paracaidismo)

## 🚀 Descripción del Problema
Este reto consiste en procesar arreglos numéricos bajo la temática de paracaidismo, aplicando lógica de coordenadas y cálculo de distancias absolutas respecto a un punto objetivo o ideal, ponderando el resultado con bonos y penalizaciones.

## 🛠️ Reglas Aplicadas
1. **Validación:** Se comprueba que el arreglo de datos contenga elementos.
2. **Cálculo de Distancia:** Se recorre la lista evaluando la desviación o distancia absoluta de cada valor con respecto a una coordenada de referencia ideal.
3. **Puntaje y Límites:** Se integra el promedio de los datos restando la penalización por distancia, sumando el bono y controlando que no arroje valores negativos.
4. **Condicionales:** Se clasifica el desempeño del salto ("aterrizaje en diana", "zona de seguridad", "fuera de zona").
