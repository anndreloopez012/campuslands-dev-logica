
# Ejercicio 033: Coordenadas y Distancia (Paracaidismo)

## 🚀 Descripción del Problema
Este reto consiste en procesar datos numéricos bajo la temática de paracaidismo, aplicando un ciclo acumulador, cálculo de distancias relativas o absolutas mediante funciones matemáticas básicas, e integrando bonos y penalizaciones para la puntuación final.

## 🛠️ Reglas Aplicadas
1. **Validación:** Se verifica que la lista de participantes contenga elementos.
2. **Ciclo y Distancia:** Se recorre el arreglo acumulando los valores base y calculando la desviación o distancia respecto a un punto de referencia usando valores absolutos.
3. **Cálculo Numérico:** Se computa el puntaje final restando la distancia promedio y aplicando el bono y la penalización.
4. **Condicionales:** Se clasifica al participante según el puntaje obtenido ("paracaidista experto", "salto preciso", "zona de riesgo").
