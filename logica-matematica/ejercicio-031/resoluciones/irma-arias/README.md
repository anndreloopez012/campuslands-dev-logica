
# Ejercicio 031: Conteo Combinatorio Simple (Kickboxing)

## 🚀 Descripción del Problema
Este reto consiste en procesar arreglos numéricos bajo la temática de kickboxing, aplicando un ciclo acumulador y un conteo combinatorio anidado para evaluar relaciones entre los datos, integrando además bonos y penalizaciones en el puntaje final.

## 🛠️ Reglas Aplicadas
1. **Validación:** Se verifica que la lista de participantes contenga elementos.
2. **Ciclos y Conteo Combinatorio:** Se recorre el arreglo para acumular la suma y se evalúan combinaciones de pares mediante bucles anidados.
3. **Cálculo Numérico:** Se computa el puntaje final incorporando la suma base, el bono, la penalización y las combinaciones obtenidas.
4. **Condicionales:** Se clasifica al participante según el puntaje obtenido ("luchador elite", "competidor avanzado", "aspirante de ring").
