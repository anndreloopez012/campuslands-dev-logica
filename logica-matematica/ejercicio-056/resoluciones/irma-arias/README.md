
# Ejercicio 056: Presupuestos y Descuentos (Animación 3D)

## 🚀 Descripción del Problema
Este reto consiste en procesar arreglos numéricos bajo la temática de animación 3D, aplicando lógica de cálculo de presupuestos, evaluación de umbrales de costos y aplicación de descuentos comerciales, ponderando el resultado con bonificaciones y penalizaciones.

## 🛠️ Reglas Aplicadas
1. **Validación:** Se comprueba que el arreglo de datos contenga elementos.
2. **Cálculo Financiero:** Se recorre la lista obteniendo el promedio del presupuesto y aplicando un descuento condicional según el volumen del costo.
3. **Puntaje Numérico:** Se integra el descuento al promedio, sumando el bono y restando la penalización.
4. **Condicionales:** Se clasifica el nivel del proyecto de animación ("produccion cinematografica 3D", "proyecto animado estandar", "modelado basico").
