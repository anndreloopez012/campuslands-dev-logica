
# Ejercicio 060: Simulaciones con Fórmulas (Comida Urbana)

## 🚀 Descripción del Problema
Este reto consiste en procesar arreglos numéricos bajo la temática de comida urbana, aplicando lógica de simulación matemática basada en fórmulas de rendimiento, costos de producción o tiempos de entrega, ponderando el resultado con bonificaciones y penalizaciones.

## 🛠️ Reglas Aplicadas
1. **Validación:** Se comprueba que el arreglo de datos contenga elementos.
2. **Simulación de Fórmulas:** Se procesa el promedio del conjunto y se aplica un factor de simulación escalado para medir la eficiencia operativa.
3. **Puntaje Numérico:** Se integra el valor simulado, sumando el bono y restando la penalización.
4. **Condicionales:** Se clasifica el tipo de servicio o establecimiento ("food truck gourmet express", "puesto callejero tradicional", "preparacion en pausa").
