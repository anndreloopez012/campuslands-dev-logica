
# Ejercicio 046: Conversión de Unidades (Autos Hiperdeportivos)

## 🚀 Descripción del Problema
Este reto consiste en procesar arreglos numéricos bajo la temática de autos hiperdeportivos, aplicando ciclos acumuladores, cálculo de promedios y conversión de unidades métricas, ajustando el puntaje final con bonos y penalizaciones.

## 🛠️ Reglas Aplicadas
1. **Validación:** Se verifica que la lista de datos de entrada contenga elementos.
2. **Ciclo y Acumulador:** Se recorre el arreglo para obtener la suma de los valores y calcular su promedio base.
3. **Conversión de Unidades:** Se aplica un factor multiplicador para transformar la escala numérica a otra unidad de rendimiento equivalente.
4. **Condicionales y Operación:** Se integra el bono, se resta la penalización y se clasifica el resultado según la categoría del vehículo ("hiperdeportivo clase a", "rendimiento aerodinamico", "prototipo en pista").
