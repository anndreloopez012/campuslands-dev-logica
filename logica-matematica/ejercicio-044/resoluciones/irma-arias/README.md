
# Ejercicio 044: Rangos y Máximos (Inventario de Motos)

## 🚀 Descripción del Problema
Este reto consiste en procesar arreglos numéricos bajo la temática de inventario de motos, aplicando ciclos acumuladores, detección del valor máximo en los datos, evaluación de rangos estadísticos y ajustando el puntaje final con bonos y penalizaciones.

## 🛠️ Reglas Aplicadas
1. **Validación:** Se verifica que la lista de participantes o unidades contenga elementos.
2. **Ciclo y Máximo:** Se recorre el arreglo calculando la suma total y encontrando el valor máximo dentro de los datos.
3. **Cálculo Numérico:** Se computa el resultado combinando el valor máximo, el promedio base, el bono y la penalización.
4. **Condicionales:** Se clasifica el estado del inventario ("inventario alto rendimiento", "stock estable", "reabastecimiento requerido").
