
# Ejercicio 040: Simulaciones con Fórmulas (Comida Urbana)

## 🚀 Descripción del Problema
Este reto consiste en procesar arreglos numéricos bajo la temática de comida urbana, aplicando un ciclo acumulador, una fórmula matemática de simulación escalada para medir rendimiento de producción, y ajustando el puntaje final con bonos y penalizaciones.

## 🛠️ Reglas Aplicadas
1. **Validación:** Se verifica que la lista de participantes o datos de entrada contenga elementos.
2. **Ciclo y Simulación:** Se recorre el arreglo calculando la suma base y aplicando una fórmula de factor ponderado de simulación.
3. **Cálculo Numérico:** Se computa el puntaje final integrando el resultado de la simulación, el bono y la penalización.
4. **Condicionales:** Se clasifica el proyecto o puesto según el puntaje obtenido ("food truck gourmet", "estación de sabor tradicional", "receta en pruebas").
