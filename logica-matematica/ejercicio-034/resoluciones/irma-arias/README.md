
# Ejercicio 034: Áreas y Perímetros (Tatuajes)

## 🚀 Descripción del Problema
Este reto consiste en procesar arreglos numéricos bajo la temática de diseño de tatuajes, aplicando un ciclo acumulador, cálculos geométricos simulados (área de superficies), y sumando bonos y penalizaciones para obtener una puntuación y clasificación final.

## 🛠️ Reglas Aplicadas
1. **Validación:** Se verifica que la lista de participantes contenga elementos.
2. **Ciclo y Geometría:** Se recorre el arreglo acumulando los valores base y calculando proporciones de área por cada elemento.
3. **Cálculo Numérico:** Se integra el factor geométrico al puntaje total junto con el bono y la penalización.
4. **Condicionales:** Se clasifica al artista o diseño según el puntaje obtenido ("tatuador master", "estudio profesional", "aprendiz de diseño").
