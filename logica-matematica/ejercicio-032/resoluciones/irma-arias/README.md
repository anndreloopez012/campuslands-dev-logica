
# Ejercicio 032: Probabilidad Básica (Ping Pong)

## 🚀 Descripción del Problema
Este reto consiste en procesar datos numéricos bajo la temática de ping pong, aplicando un ciclo acumulador, cálculo de casos favorables sobre el total (probabilidad básica porcentual), y combinando estos factores con bonos y penalizaciones para obtener una clasificación consolidada.

## 🛠️ Reglas Aplicadas
1. **Validación:** Se verifica que la lista de participantes contenga elementos.
2. **Ciclo y Probabilidad:** Se recorre el arreglo acumulando los puntajes y calculando la probabilidad de ocurrencia de elementos que cumplen con una condición dada.
3. **Cálculo Numérico:** Se integra el porcentaje de probabilidad obtenido al puntaje total junto con el bono y la penalización.
4. **Condicionales:** Se clasifica al jugador o grupo según el nivel de probabilidad ("pelotaris experto", "saque competitivo", "novato de mesa").
