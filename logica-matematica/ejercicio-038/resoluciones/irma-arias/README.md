
# Ejercicio 038: Normalización de Puntajes (Soldadura)

## 🚀 Descripción del Problema
Este reto consiste en procesar arreglos numéricos bajo la temática de soldadura, aplicando un ciclo acumulador, procesos de normalización matemática de los datos (escala respecto al valor máximo), y ajustando el puntaje final con bonos y penalizaciones.

## 🛠️ Reglas Aplicadas
1. **Validación:** Se verifica que la lista de participantes contenga elementos.
2. **Ciclo y Normalización:** Se recorre el arreglo acumulando la suma y detectando el valor máximo para escalar la métrica general.
3. **Cálculo Numérico:** Se computa el puntaje final combinando el valor normalizado, el bono y la penalización.
4. **Condicionales:** Se clasifica el nivel del proceso según el puntaje final obtenido ("soldador experto MIG/TIG", "calidad estructural aprobada", "revision de cordon requerida").
