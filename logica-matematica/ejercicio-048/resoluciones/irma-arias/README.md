
# Ejercicio 048: Patrones de Puntuación (Películas de Ciencia Ficción)

## 🚀 Descripción del Problema
Este reto consiste en procesar arreglos numéricos bajo la temática de películas de ciencia ficción, aplicando ciclos acumuladores, detección y aplicación de patrones de puntuación condicionales por posición y ajustando el puntaje final con bonos y penalizaciones.

## 🛠️ Reglas Aplicadas
1. **Validación:** Se verifica que la lista de datos de entrada contenga elementos.
2. **Ciclo y Patrones:** Se recorre el arreglo aplicando un factor ponderado diferente a los elementos según su posición (pares e impares).
3. **Cálculo Numérico:** Se obtiene el promedio ponderado del patrón, sumando el bono y restando la penalización.
4. **Condicionales:** Se clasifica el resultado según las categorías temáticas ("universo cyberpunk", "opera espacial", "distopia basica").
