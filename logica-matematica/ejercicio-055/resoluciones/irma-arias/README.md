
# Ejercicio 055: Velocidad, Tiempo y Distancia (Dibujo Digital)

## 🚀 Descripción del Problema
Este reto consiste en procesar arreglos numéricos bajo la temática de dibujo digital, aplicando fórmulas de cinemática (velocidad, tiempo y distancia) para modelar la velocidad de los trazos y el rendimiento del renderizado, ponderando el resultado con bonificaciones y penalizaciones.

## 🛠️ Reglas Aplicadas
1. **Validación:** Se comprueba que el arreglo de datos contenga elementos.
2. **Cálculo Cinemático:** Se recorre la lista simulando la relación de distancia recorrida por los trazos a partir de la velocidad de ejecución y un tiempo constante.
3. **Puntaje Numérico:** Se computa el promedio de la distancia obtenida, sumando el bono y restando la penalización.
4. **Condicionales:** Se clasifica el nivel del artista digital ("trazo fluido avanzado", "estilo en desarrollo", "trazos basicos").
