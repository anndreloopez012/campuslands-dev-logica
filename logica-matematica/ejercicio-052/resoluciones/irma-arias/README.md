
# Ejercicio 052: Probabilidad Básica (Ping Pong)

## 🚀 Descripción del Problema
Este reto consiste en procesar arreglos numéricos bajo la temática de ping pong, aplicando cálculos de probabilidad básica (casos favorables sobre el total) para ponderar el puntaje final junto con bonificaciones y penalizaciones.

## 🛠️ Reglas Aplicadas
1. **Validación:** Se comprueba que el arreglo de participantes contenga elementos.
2. **Cálculo de Probabilidad:** Se determina un factor porcentual evaluando cuántos participantes superan el promedio del grupo.
3. **Puntaje y Redondeo:** Se integra la probabilidad ponderada al promedio general, sumando el bono y restando la penalización.
4. **Condicionales:** Se asigna una categoría de rendimiento en el tenis de mesa ("maestro de raqueta", "jugador avanzado", "jugador recreativo").
