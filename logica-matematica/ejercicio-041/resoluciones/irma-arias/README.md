
# Ejercicio 041: Operaciones Aritméticas Controladas (Videojuegos Competitivos)

## 🚀 Descripción del Problema
Este reto consiste en procesar arreglos numéricos bajo la temática de videojuegos competitivos, aplicando un ciclo acumulador, operaciones aritméticas controladas (como división entera, promedios y límites condicionales), y ajustando el resultado final con bonos y penalizaciones.

## 🛠️ Reglas Aplicadas
1. **Validación:** Se verifica que la lista de participantes contenga elementos.
2. **Ciclo y Acumulador:** Se recorre el arreglo para obtener la suma de los puntajes base.
3. **Cálculo Numérico y Control:** Se calcula el promedio, se aplica el bono, se resta la penalización y se asegura que el resultado no sea negativo.
4. **Condicionales:** Se clasifica el rendimiento del jugador según el puntaje final ("competitivo", "rango platino", "rango plata").
