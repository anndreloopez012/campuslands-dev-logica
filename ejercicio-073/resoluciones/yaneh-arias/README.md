# Ejercicio 073: Coordenadas y Distancia en Paracaidismo

## ¿Cómo pensé el problema?
1. Analicé las entradas: dos puntos en un plano cartesiano representados como coordenadas (x, y) para el punto de salto y el punto de aterrizaje.
2. Apliqué la fórmula de la distancia euclidiana basada en el teorema de Pitágoras.
3. Redondeé el resultado final a dos cifras decimales para mayor precisión técnica.

## Reglas Aplicadas
* Validación de estructuras de coordenadas de tamaño correcto (pares ordenados).
* Uso de funciones matemáticas nativas (Math.sqrt) respetando la regla de no usar librerías externas complejas.

## Casos Probados
* **Caso Normal:** Distancia entre el origen (0,0) y el punto (3,4).
* **Caso Borde:** Distancia entre un punto y sí mismo para validar cero desplazamiento.
