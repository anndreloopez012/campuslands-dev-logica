# Ejercicio 071: Conteo Combinatorio Simple en Kickboxing

## ¿Cómo pensé el problema?
1. Analicé las entradas: el número de opciones de golpes y opciones de patadas disponibles en una combinación de kickboxing.
2. Apliqué el principio fundamental del conteo (multiplicación) para calcular todas las combinaciones posibles entre ambas técnicas.
3. Estructuré una función auxiliar para cálculos factoriales y validé los datos de entrada para evitar errores con números negativos o ceros.

## Reglas Aplicadas
* Validación de rangos mayores a cero para las opciones tácticas.
* Uso de funciones separadas para mantener el código ordenado y modular.

## ¿Cómo ejecutar la solución?
1. Abre tu terminal en: \ejercicio-071/resoluciones/yaneh-arias/\
2. Ejecuta: \
ode yaneh-arias.js\

## Casos Probados
* **Caso Normal:** 4 opciones de golpes y 3 de patadas.
* **Caso Borde:** 0 opciones de golpes para validar la restricción lógica.
