# Ejercicio 065: Filtrado y Transformación de Datos

## ¿Cómo pensé el problema?
1. Recibí una lista de valores numéricos y un número de referencia (umbral).
2. Utilicé el método de filtrado para conservar únicamente los números que cumplen con la condición del umbral.
3. Acumulé la suma total de los elementos filtrados para obtener el resultado final.

## Reglas Aplicadas
* Validación estricta de arreglos vacíos.
* Uso de funciones nativas de orden superior (filter y reduce).

ode yaneh-arias.js\

* **Caso Normal:** Lista de números mixtos con umbral de 10.
* **Caso Borde:** Lista vacía para comprobar la robustez ante datos nulos.
