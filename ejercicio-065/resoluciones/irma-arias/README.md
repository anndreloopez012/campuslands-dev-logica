
# Ejercicio 065: Taller Mecánico - Ordenamiento de prioridades

## ¿Cómo pensé el problema?
Analicé que un taller mecánico maneja múltiples ingresos vehiculares donde algunos problemas (como fallas de frenos) representan un riesgo mayor que otros (como revisiones de rutina). Por lo tanto, se requiere un algoritmo capaz de clasificar, ponderar y ordenar los elementos según su nivel crítico.

## Reglas aplicadas
1. Validar que la lista de vehículos no esté vacía antes de procesarla.
2. Asignar un valor numérico de peso a cada nivel de prioridad (*urgente*, *moderado*, *rutina*).
3. Ordenar de manera ascendente según el nivel de urgencia.
4. Aplicar un criterio de desempate secundario basado en el tiempo de espera (mayor tiempo acumulado pasa primero ante igual prioridad).

## Cómo ejecutar o revisar la solución
1. Asegúrate de tener instalado Node.js en tu equipo.
