# Ejercicio 066: Conversión de Unidades en Autos Hiperdeportivos

## ¿Cómo pensé el problema?
1. Identifiqué las unidades de entrada típicas de autos de alta gama (millas por hora a kilómetros por hora, o caballos de fuerza a kilovatios).
2. Establecí condiciones para aplicar el factor de multiplicación correcto según la conversión solicitada.
3. Redondeé el resultado a dos cifras decimales para mantener la precisión técnica.

## Reglas Aplicadas
* Validación de entradas numéricas y nulas.
* Factores de conversión físicos estandarizados.

## ¿Cómo ejecutar la solución?
1. Abre tu terminal en: \ejercicio-066/resoluciones/yaneh-arias/\
2. Ejecuta: \
ode yaneh-arias.js\

## Casos Probados
* **Caso Normal:** Conversión de 250 mph a km/h.
* **Caso Borde:** Conversión de 0 hp a kW para evaluar valores límite.
