# Ejercicio 069: Módulos y Divisibilidad en Películas de Miedo

## ¿Cómo pensé el problema?
1. Recibí el valor de la duración en minutos de la película y el divisor base.
2. Apliqué la operación módulo (%) para obtener el residuo de la división.
3. Evalué si el residuo es igual a cero para determinar la regla de divisibilidad exacta.

## Reglas Aplicadas
* Validación contra división por cero y valores nulos.
* Uso de operador aritmético de módulo (%).

## ¿Cómo ejecutar la solución?
1. Abre tu terminal en: \ejercicio-069/resoluciones/yaneh-arias/\
2. Ejecuta: \
ode yaneh-arias.js\

## Casos Probados
* **Caso Normal:** Duración de 120 minutos con divisor de 15.
* **Caso Borde:** Duración de 0 minutos para validar el comportamiento base.
