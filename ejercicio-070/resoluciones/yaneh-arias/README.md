# Ejercicio 070: Redondeo y Precisión en Viajes y Turismo

## ¿Cómo pensé el problema?
1. Recibí una lista con los costos base de los servicios turísticos y el porcentaje de impuesto aplicable.
2. Sumé los elementos para obtener un subtotal y le agregué el impuesto correspondiente.
3. Utilicé el método de redondeo y precisión con decimales para entregar un presupuesto financiero exacto.

## Reglas Aplicadas
* Validación de arreglos vacíos e impuestos negativos.
* Uso de control de precisión numérica con toFixed y conversión a número.

## ¿Cómo ejecutar la solución?
1. Abre tu terminal en: \ejercicio-070/resoluciones/yaneh-arias/\
2. Ejecuta: \
ode yaneh-arias.js\

## Casos Probados
* **Caso Normal:** Lista con tres costos base y una tasa impositiva del 16%.
* **Caso Borde:** Lista vacía para comprobar la validación segura de datos.
