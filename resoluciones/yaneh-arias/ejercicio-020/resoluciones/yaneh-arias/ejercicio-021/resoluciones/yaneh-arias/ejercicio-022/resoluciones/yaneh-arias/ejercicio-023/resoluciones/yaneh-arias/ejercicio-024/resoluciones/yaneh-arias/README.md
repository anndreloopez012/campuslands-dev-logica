# Ejercicio 061: Operaciones Aritméticas Controladas

## ¿Cómo pensé el problema?
1. Analicé que la entrada contiene un arreglo de puntajes de participantes, un valor de bono y una penalización.
2. Diseñé un acumulador mediante un ciclo para sumar todos los valores y obtener un promedio base.
3. Apliqué las operaciones aritméticas controladas sumando el bono y restando la penalización, redondeando el resultado final.
4. Establecí condiciones lógicas para clasificar el puntaje final en categorías (*elite*, *competitivo*, *novato*).

## Reglas Aplicadas
* Validación de arreglos vacíos para evitar errores de ejecución.
* Uso de ciclos y acumuladores para recorrer los datos.
* Estructuras condicionales para determinar la clasificación final.
