
# Ejercicio 016: Presupuestos y Descuentos

## Pensamiento
El problema se resolvió sumando una lista de precios, aplicando una regla condicional para el descuento y clasificando el resultado final.

## Reglas aplicadas
- Si la suma supera 100, se aplica el 10% de descuento.
- Si el total es mayor a 50, el proyecto se clasifica como 'proyecto_grande'.

## Ejecución
`node yaneh-arias.js`

## Casos de prueba
- Normal: [50, 60, 20] -> Subtotal: 130, Total: 117.
- Borde: [10, 10] -> Subtotal: 20, Total: 20.
