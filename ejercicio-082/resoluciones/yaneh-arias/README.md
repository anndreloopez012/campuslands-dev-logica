# Ejercicio 082: Porcentajes y Proporciones en Ranking de Fútbol Sala

## ¿Cómo pensé el problema?
1. Analicé las entradas: el total de partidos jugados y los partidos ganados por un equipo de fútbol sala.
2. Apliqué la operación de proporción dividiendo los partidos ganados entre los partidos jugados.
3. Transformé el resultado en un porcentaje exacto con control de decimales y validé los límites lógicos.

## Reglas Aplicadas
* Validación contra división por cero o datos incoherentes (partidos ganados mayores a los jugados).
* Uso de funciones estructuradas para mantener el código limpio y modular.

## ¿Cómo ejecutar la solución?
1. Abre tu terminal en: \ejercicio-082/resoluciones/yaneh-arias/\
2. Ejecuta: \
ode yaneh-arias.js\

## Casos Probados
* **Caso Normal:** 20 partidos jugados y 15 ganados.
* **Caso Borde:** 0 partidos jugados para comprobar la respuesta segura del sistema.
