# Ejercicio 086: Conversión de Unidades en Autos Hiperdeportivos

## ¿Cómo pensé el problema?
1. Analicé las entradas: el valor numérico de la velocidad y el sentido de la conversión requerida (de kilómetros por hora a metros por segundo, o viceversa).
2. Utilicé factores de conversión estándar (la constante 3.6) aplicando condicionales para direccionar la operación matemática correcta.
3. Estructuré el resultado controlando la precisión decimal y validando que no ingresaran velocidades negativas.

## Reglas Aplicadas
* Validación de rangos numéricos no negativos.
* Uso de condicionales para manejo de tipos de conversión específicos.

## ¿Cómo ejecutar la solución?
1. Abre tu terminal en: \ejercicio-086/resoluciones/yaneh-arias/\
2. Ejecuta: \
ode yaneh-arias.js\

## Casos Probados
* **Caso Normal:** Conversión de 360 km/h a m/s.
* **Caso Borde:** Conversión con valor de velocidad en cero para verificar el comportamiento estático.
