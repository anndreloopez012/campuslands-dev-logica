# Ejercicio 088: Patrones de Puntuación en Películas de Ciencia Ficción

## ¿Cómo pensé el problema?
1. Analicé las entradas: una lista con las puntuaciones de las críticas recibidas por una película de ciencia ficción a lo largo del tiempo.
2. Recorrí el arreglo evaluando si los valores consecutivos aumentan, disminuyen o se mantienen estables.
3. Clasifiqué el comportamiento general en patrones claros (creciente, decreciente o irregular) mediante condicionales estructurados.

## Reglas Aplicadas
* Validación de listas de puntuaciones vacías.
* Verificación iterativa de tendencias numéricas consecutivas.

## ¿Cómo ejecutar la solución?
1. Abre tu terminal en: \ejercicio-088/resoluciones/yaneh-arias/\
2. Ejecuta: \
ode yaneh-arias.js\

## Casos Probados
* **Caso Normal:** Lista con calificaciones en aumento constante ([7.0, 7.5, 8.2, 9.0]).
* **Caso Borde:** Lista con puntuaciones totalmente idénticas para verificar el comportamiento ante valores constantes.
