# Ejercicio 068: Patrones de Puntuación en Películas de Ciencia Ficción

## ¿Cómo pensé el problema?
1. Recibí una lista con las puntuaciones asignadas a diferentes películas de ciencia ficción.
2. Recorrí los datos acumulando la suma para calcular el promedio, a la vez que identifiqué los valores extremos (máximo y mínimo).
3. Clasifiqué el resultado general según un criterio de calidad basado en el promedio obtenido.

## Reglas Aplicadas
* Validación de arreglos vacíos para prevenir errores de división por cero.
* Uso de acumuladores y comparadores para hallar máximos y mínimos.

## ¿Cómo ejecutar la solución?
1. Abre tu terminal en: \ejercicio-068/resoluciones/yaneh-arias/\
2. Ejecuta: \
ode yaneh-arias.js\

## Casos Probados
* **Caso Normal:** Lista con cuatro valoraciones de películas de ciencia ficción.
* **Caso Borde:** Lista vacía para validar el comportamiento seguro del sistema.
