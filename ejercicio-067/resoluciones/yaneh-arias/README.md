# Ejercicio 067: Secuencias Numéricas en Lista de Reproducción Musical

## ¿Cómo pensé el problema?
1. Analicé la entrada: una lista con las duraciones de las canciones de la lista de reproducción.
2. Recorrí el arreglo mediante un ciclo para verificar si cada canción tiene una duración mayor a la anterior, validando una secuencia estrictamente creciente.
3. Retorné el análisis indicando si la secuencia de reproducción es válida o no.

## Reglas Aplicadas
* Validación de listas vacías.
* Control de índices en ciclos para comparar elementos consecutivos.

## ¿Cómo ejecutar la solución?
1. Abre tu terminal en: \ejercicio-067/resoluciones/yaneh-arias/\
2. Ejecuta: \
ode yaneh-arias.js\

## Casos Probados
* **Caso Normal:** Lista de duraciones en orden ascendente.
* **Caso Borde:** Lista con un desorden en las duraciones para validar la regla de secuencia.
