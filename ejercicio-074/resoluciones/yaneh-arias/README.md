# Ejercicio 074: Áreas y Perímetros en Tatuajes

## ¿Cómo pensé el problema?
1. Analicé las entradas: el tipo de figura geométrica del diseño del tatuaje (rectángulo o círculo) y su arreglo de dimensiones (largo/ancho o radio).
2. Utilicé condicionales para aplicar las fórmulas matemáticas correspondientes de área y perímetro para cada caso.
3. Redondeé los resultados finales a dos decimales para mantener la precisión en la estimación de la piel y la tinta requerida.

## Reglas Aplicadas
* Validación de estructuras de dimensiones vacías o insuficientes.
* Modularización mediante condicionales según la figura geométrica.

## ¿Cómo ejecutar la solución?
1. Abre tu terminal en: \ejercicio-074/resoluciones/yaneh-arias/\
2. Ejecuta: \
ode yaneh-arias.js\

## Casos Probados
* **Caso Normal:** Rectángulo con dimensiones de 10x5.
* **Caso Borde:** Círculo con radio 0 para comprobar el comportamiento ante medidas nulas.
