# Ejercicio 094: Áreas y Perímetros en Tatuajes

## ¿Cómo pensé el problema?
1. Analicé las entradas: las dimensiones de base y altura del diseño del tatuaje, junto con el tipo de forma geométrica.
2. Apliqué fórmulas matemáticas para determinar la superficie (área) y el contorno total (perímetro).
3. Estructuré la salida validando que las medidas ingresadas fueran estrictamente positivas.

## Reglas Aplicadas
* Validación de dimensiones numéricas mayores a cero para evitar resultados nulos o ilógicos.
* Aplicación de fórmulas geométricas diferenciadas por tipo de diseño.

## ¿Cómo ejecutar la solución?
1. Abre tu terminal en: \ejercicio-094/resoluciones/yaneh-arias/\
2. Ejecuta: \
ode yaneh-arias.js\

## Casos Probados
* **Caso Normal:** Rectángulo con base 10 y altura 5.
* **Caso Borde:** Base en cero para comprobar la respuesta segura del sistema ante dimensiones inválidas.
