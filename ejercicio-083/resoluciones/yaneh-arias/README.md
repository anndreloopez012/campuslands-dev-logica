# Ejercicio 083: Promedios y Medianas en Torneo de Esports

## ¿Cómo pensé el problema?
1. Analicé las entradas: una lista con las puntuaciones obtenidas por los equipos en el torneo de esports.
2. Sumé los elementos y los dividí entre el total para hallar el promedio aritmético.
3. Ordené los valores de menor a mayor para encontrar el valor central (mediana), manejando tanto cantidades pares como impares de elementos.

## Reglas Aplicadas
* Validación de arreglos vacíos para prevenir errores aritméticos.
* Ordenamiento seguro y cálculo exacto de la posición central.

2. Ejecuta: \
ode yaneh-arias.js\
