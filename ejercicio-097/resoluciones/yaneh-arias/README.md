# Ejercicio 097: Estadísticas de Ranking en Arquitectura 3D

## ¿Cómo pensé el problema?
1. Analicé las entradas: un arreglo de números que representan las calificaciones de los proyectos de arquitectura 3D en el ranking.
2. Recorrí la lista mediante un ciclo iterativo para extraer de forma segura el puntaje máximo, el puntaje mínimo y acumular la suma para el promedio.
3. Estructuré un objeto de salida claro con los indicadores estadísticos clave y control de decimales.

## Reglas Aplicadas
* Validación de listas de puntajes vacías para prevenir fallos de ejecución.
* Uso de acumuladores y condicionales internos para la obtención de extremos numéricos.

## ¿Cómo ejecutar la solución?
1. Abre tu terminal en: \ejercicio-097/resoluciones/yaneh-arias/\
2. Ejecuta: \
ode yaneh-arias.js\

## Casos Probados
* **Caso Normal:** Lista de cinco calificaciones de diseños arquitectónicos.
* **Caso Borde:** Lista con un solo puntaje para comprobar el comportamiento ante muestras unitarias.
